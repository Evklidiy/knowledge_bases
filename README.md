# Лабораторная работа №3: Методы распознавания в экспертных системах

**Дисциплина:** Базы знаний и поддержка принятия решений  
**Тема:** Методы и алгоритмы распознавания образов (на основе минимального расстояния и алгоритма восприятия).

## 📝 Описание предметной области (Вариант 12)
В качестве предметной области разработана экспертная система для **классификации состояний компьютерной сети**. Система анализирует сетевой трафик и относит его к одному из двух классов:
*   **Класс 1 (Норма):** Штатное состояние сети (низкие значения метрик).
*   **Класс 2 (Аномалия / DDoS):** Вредоносная активность или перегрузка сети (высокие значения метрик).

Для распознавания используется 5 нормализованных признаков (в диапазоне от 0 до 1):
1. Интенсивность пакетов
2. Средний размер пакета
3. Доля ошибок передачи
4. Задержка (Ping)
5. Джиттер (вариация задержки)

Обучающее множество состоит из 12 объектов (по 6 типичных представителей для каждого класса).

## 🧠 Реализованные алгоритмы
Программа реализует два независимых метода классификации:
1.  **На основе минимального расстояния:** Вычисляются объекты-прототипы (центры масс) для каждого класса. Распознаваемый объект относится к классу, расстояние до прототипа которого (в 5-мерном пространстве) минимально. Расчет ведется через дискриминантные функции $D_i$.
2.  **Разделяющая решающая функция (Перцептрон):** Реализован алгоритм восприятия, который итеративно подбирает весовые коэффициенты $W_0 \dots W_5$ гиперплоскости, разделяющей два класса, пока обучающая выборка не будет распознаваться без ошибок (либо до достижения лимита итераций).

## 📐 Геометрическая интерпретация
Особенностью приложения является динамическая геометрическая проекция 5-мерного признакового пространства на 2D-плоскость (по осям $X_1$ и $X_2$). 
Так как решающие границы зависят от всех 5 признаков, при изменении пользователем параметров $X_3, X_4, X_5$ через ползунки, линии разделения классов на графике динамически смещаются, отражая сечение многомерного пространства.

## 📂 Структура проекта
*   `data.py` — Описание признаков и формирование обучающего множества.
*   `model.py` — Вычислительное ядро с реализацией классов `MinDistanceClassifier` и `PerceptronClassifier`.
*   `app.py` — Графический интерфейс `CustomTkinter` с выводом текстовых результатов и интерактивным графиком `Matplotlib`.
