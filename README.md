# Лабораторная работа №2: Многокритериальный выбор (Метод ЭЛЕКТРА)

**Дисциплина:** Базы знаний и поддержка принятия решений  
**Тема:** Методы принятия решений при многих критериях.

## 📝 Описание задачи
Предлагаются шесть проектов строительства промышленного предприятия. Необходимо выбрать оптимальный проект на основе трех противоречивых критериев (все критерии подлежат максимизации):
1. **Прибыль** (млн ден.ед./год)
2. **Новые рабочие места** (количество)
3. **Возможности развития территории** (качественная оценка: от "средние" до "очень хорошие").

Для приведения качественных оценок к единой форме используется **шкала Харрингтона**. Важность критериев оценивается двумя экспертами методом рангов (наиболее важный критерий получает 3 балла, наименее важный — 1 балл). 

**Задача:** 
1. Исключить заведомо худшие варианты путем отбора множества **Парето-оптимальных решений**.
2. Вычислить весовые коэффициенты критериев на основе экспертных оценок.
3. Выполнить анализ отобранных альтернатив по методу **ЭЛЕКТРА** (вычисление индексов согласия $c$ и несогласия $d$) и выделить ядро лучших проектов, варьируя пороговые значения $c^*$ и $d^*$.

## 📂 Структура проекта

Проект разделен на логические модули для удобства сопровождения:
*   `data.py` — Исходные данные, оцифровка качественных метрик по шкале Харрингтона и матрицы экспертных ранжировок.
*   `model.py` — Вычислительное ядро. Содержит векторизованные математические алгоритмы (NumPy) для нормализации матрицы, поиска фронта Парето, расчета весов и вычисления матриц согласия/несогласия.
*   `app.py` — Графический интерфейс (GUI) на базе `CustomTkinter`. Реализован в виде аналитического дашборда с возможностью динамического изменения порогов $c^*$ и $d^*$, табличным выводом результатов и интерактивной визуализацией карты Парето-оптимальных проектов через `Matplotlib`.

## 🚀 Запуск программы

1. Убедитесь, что установлен Python 3.10+ и необходимые библиотеки:
   ```bash
   pip install customtkinter matplotlib numpy
   ```
2. Запустите графический интерфейс:
   ```bash
   python app.py
   ```
