# Лабораторная работа №5: Нейронная сеть Хопфилда

**Дисциплина:** Базы знаний и поддержка принятия решений  
**Тема:** Топология и алгоритмы функционирования автоассоциативной нейронной сети.

## 📝 Описание задачи (Вариант 12)
Требуется разработать и обучить классическую полносвязную нейронную сеть Хопфилда (однослойная, симметричная, с обратными связями). В качестве тренировочной выборки выступают 3 бинарных изображения размером $5 \times 7$ (первые три буквы фамилии: **П, Л, Е**). 

**Цель:** Обучить сеть, подать на ее вход искаженные (зашумленные) тестовые образы и проанализировать восстановительную способность сети в зависимости от процента внесенного шума.

## 🧠 Архитектура сети
1. **Топология:** Автоассоциативная сеть на 35 нейронов (соответствует пикселям сетки 5х7). Состояние нейронов кодируется биполярным сигналом $[-1; 1]$.
2. **Обучение (Правило Хебба):** Синаптические веса рассчитываются как сумма внешних произведений векторов обучающей выборки $W = \sum (a \cdot a^T)$. Главная диагональ принудительно обнуляется ($w_{ii} = 0$), чтобы исключить влияние нейрона на самого себя.
3. **Функционирование (Распознавание):** Реализовано **асинхронное обновление**. На каждом шаге нейроны обновляются в случайном порядке на основе пороговой функции от взвешенной суммы входов. Итерации продолжаются до достижения энергетического минимума (пока состояние сети не перестанет изменяться).

## 📊 Анализ устойчивости к шуму
Программный комплекс содержит отдельный модуль автоматизированного пакетного тестирования. 
Согласно требованиям, для каждого из заданных процентов шума (10%, 20%, 30%, 35%, 40%, 45%, 50%, 60%, 70%, 80%, 90%, 100%) программно генерируется **по 10 уникальных искаженных образов** для каждого класса. 
На основе 360 прогонов (3 класса $\times$ 12 уровней шума $\times$ 10 тестов) строится итоговый линейный график зависимости вероятности успешного распознавания от степени повреждения исходных данных.

## 📂 Структура проекта
*   `data.py` — Генерация биполярных матриц образов (П, Л, Е) и алгоритм псевдослучайной инверсии битов для внесения контролируемого шума.
*   `model.py` — Вычислительный модуль (`HopfieldNetwork`).
*   `app.py` — GUI на `CustomTkinter`. Включает две вкладки: визуализацию попиксельного восстановления в реальном времени и вкладку пакетного тестирования с отрисовкой итогового графика `Matplotlib`.
