# Лабораторная работа №1: Оптимизация методом Монте-Карло

**Дисциплина:** Базы знаний и поддержка принятия решений  
**Тема:** Принятие решений на основе метода Монте-Карло в производственно-экономических задачах.

## 📝 Описание задачи
На предприятие радиоэлектронной промышленности поступают комплектующие с допуском невысокой точности (резисторы с разбросом 15%). Статистически определенный процент деталей имеет отклонения и требует дополнительной подгонки. 

Предприятию необходимо найти баланс: если не проводить входной контроль, бракованные детали попадут в готовое изделие, и их замена обойдется очень дорого. Если проверять 100% деталей, возрастут прямые накладные расходы на контроль. 

**Задача:** С помощью стохастического моделирования найти оптимальную долю резисторов, которую нужно подвергать входному контролю, чтобы минимизировать суммарные финансовые потери.

## ⚙️ Исходные данные (Вариант 12)

*   **A (Доля брака):** 7%
*   **B (Стоимость контроля 1 шт):** 5 руб.
*   **C (Стоимость подгонки брака):** 55 руб.
*   **D (Стоимость замены в готовом изделии):** 95 руб.
*   **Генератор ПСЧ:** 32-битный LFSR (Сдвиговый регистр с линейной обратной связью).
*   **Полином (№12):** $X^{32} + X^{29} + X^{28} + X^{23} + X^{22} + X^{21} + X^{16} + X^{13} + X^{10} + X^6 + X^5 + X^4 + 1$

## 📂 Структура проекта

*   `lfsr.py` — Модуль собственной реализации генератора случайных чисел на базе аппаратного регистра сдвига (LFSR) для полинома №12.
*   `monte_carlo.py` — Математическое ядро. Модуль статистических испытаний, который прогоняет серии из $N$ тестов для каждого процента контроля (с шагом 5%).
*   `app.py` — Графический интерфейс пользователя (GUI), реализованный на `CustomTkinter`. Позволяет изменять параметры, запускать расчет и визуализировать результаты (таблица + график `Matplotlib`).

## 🚀 Запуск программы

1. Убедитесь, что у вас установлен Python версии 3.10 или выше.
2. Установите необходимые зависимости:
   
```bash
   pip install customtkinter matplotlib
```bash
3. Запустите главный файл:

```bash
   python app.py
```bash
