# Базы знаний и поддержка принятия решений

Данный репозиторий содержит лабораторный практикум по дисциплине «Базы знаний и поддержка принятия решений». 
Проекты реализованы на языке **Python** и разделены по отдельным веткам (`lab1` - `lab5`).

## 📚 Структура репозитория

Для перехода к конкретной лабораторной работе необходимо переключиться на соответствующую ветку (например, `git checkout lab1`).

### [Ветка `lab1`] Лабораторная работа 1: Принятие решений на основе метода Монте-Карло
**Цель:** Изучение эффективности применения метода Монте-Карло для поддержки принятия решений в производственно-экономических задачах.
**Краткие сведения:** Реализована имитационная модель предприятия радиоэлектронной промышленности. Программа определяет оптимальную долю входного контроля комплектующих, при которой суммарные затраты на контроль, подгонку и замену бракованных деталей минимальны. Для генерации случайностей реализован собственный сдвиговый регистр с линейной обратной связью (LFSR) по заданному полиному.

### [Ветка `lab2`] Лабораторная работа 2: Методы принятия решений при многих критериях
**Цель:** Изучение метода ЭЛЕКТРА (ELECTRE) для принятия решений в производственно-технологических задачах.
**Краткие сведения:** Реализована система многокритериальной оптимизации для выбора лучшей альтернативы (например, выбор поставщика или проекта) в условиях противоречивых критериев. Процесс включает приведение оценок к единой форме, экспертный анализ (метод ранга/алгоритм Саати), отбор множества Парето-оптимальных решений и финальный выбор с помощью вычисления индексов согласия и несогласия по методу ЭЛЕКТРА.

### [Ветка `lab3`] Лабораторная работа 3: Методы распознавания в экспертных системах
**Цель:** Изучение методов и алгоритмов распознавания образов, применяемых в базах знаний.
**Краткие сведения:** Реализовано отнесение объекта (ситуации) к одному из известных классов на основе вектора его признаков. В работе применяются два подхода:
1. **Решающие функции на основе минимального расстояния** (поиск ближайшего эталона/прототипа класса с использованием евклидова расстояния).
2. **Разделяющие решающие функции** (построение линейной границы между классами с помощью обучающего множества и алгоритма восприятия/перцептрона).

### [Ветка `lab4`] Лабораторная работа 4: Методы кластерного анализа
**Цель:** Изучение методов разделения объектов на группы (кластеры) по их признакам.
**Краткие сведения:** Реализовано два алгоритма кластеризации для упорядочивания информации и сжатия данных предметной области:
1. **Метод К-средних (K-means):** разбиение объектов на заранее заданное число кластеров путем итеративного пересчета центров масс.
2. **Метод максимина:** автоматическое определение количества кластеров и распределение объектов на основе заданного порогового расстояния.

### [Ветка `lab5`] Лабораторная работа 5: Нейронная сеть Хопфилда
**Цель:** Изучение топологии и алгоритма функционирования автоассоциативной нейронной сети.
**Краткие сведения:** Реализована однослойная симметричная нелинейная нейронная сеть с обратными связями (модель Хопфилда). Сеть обучается запоминать бинарные/биполярные образы (например, буквы в виде матрицы пикселей). Основная задача программы — успешное распознавание и восстановление исходного образа при подаче на вход тестовых данных с различным уровнем зашумления (от 10% до 100%).

**Стек технологий:** Python 3.10+, CustomTkinter (GUI), Matplotlib.
